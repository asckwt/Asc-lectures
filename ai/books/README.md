# كتب المواد

ملف لكل مادة باسم رمزها، مثل `ACC204.md`. اكتب فيه اسم الكتاب والطبعة والمؤلف وأسماء الشباتر،
والمساعد يربط شرحه بالشابتر المناسب. لا تنسخ محتوى الكتاب نفسه (حقوق نشر)، بس الفهرس.

مثال:

```
Intermediate Accounting, 18th edition (Kieso, Weygandt, Warfield), Pearson/Wiley
- Chapter 1: Financial Accounting and Accounting Standards
- Chapter 2: Conceptual Framework for Financial Reporting
```
